1Admin Access

Ilagay ang iyong GitHub Admin Key. Kailangan lang ito para mapatunayan na ikaw ang authorized administrator.

Secure: Hindi kasama sa website code ang Admin Key. Sa kasalukuyang browser tab/session lang ito pansamantalang itinatago. Huwag itong i-share.
First time? Paano gumawa ng Admin Key
  1. Buksan ang GitHub Fine-grained Token page at mag-login.
  2. Token name: JETRIDERS Photo Upload.
  3. Sa Repository access, piliin ang Only select repositories, tapos piliin ang jetridersclubpampangainc.
  4. Sa Repository permissions, click Add permissions, check ang Contents, at isara ang black menu.
  5. Sa dropdown sa kanan ng Contents, piliin ang Read and write. Iwanang Read-only ang Metadata.
  6. Click Generate token, copy ito, at i-paste sa Admin Key box.
Important: Isang beses lang ipapakita ng GitHub ang token. I-save sa password manager at huwag ipadala sa chat o GC.
